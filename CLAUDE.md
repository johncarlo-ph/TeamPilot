# Project Development Guidelines

Before making any changes to this project, read and follow the applicable guidelines in the `constitution` folder:

- `constitution/.NET-Core-API-Development-Guidelines.MD` for .NET Core API and backend development.
- `constitution/Angular-20-UI-Development-Guidelines.MD` for Angular UI and frontend development.

When a task spans both backend and frontend code, read and apply both guideline files. These guidelines are required project conventions and should be followed together with the existing codebase patterns and project configuration.
